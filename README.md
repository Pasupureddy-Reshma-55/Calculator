# 🧮 Calculator App

A simple and user-friendly **Calculator App** built to perform basic mathematical calculations quickly and easily.

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🧹 Clear/reset functionality
* 🔢 Decimal number support
* 📱 Responsive and clean interface
* ⚡ Fast and easy to use

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Navigate to the project

```bash
cd calculator
```

### 3. Run the application

Open `index.html` in your browser.

You can also use **Live Server** in VS Code.

## 🎯 How to Use

1. Enter numbers using the calculator buttons.
2. Select an arithmetic operation.
3. Enter the second number.
4. Press `=` to calculate the result.
5. Press `C` or `AC` to clear the calculation.
